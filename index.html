This page must be served over HTTP

ES modules are CORS-blocked on the file:// scheme, so opening index.html straight from disk loads nothing. From the repository root run: 

npm start

That starts tools/serve.js — a zero-dependency static server — and opens http://localhost:8080/index.html. Any other static server on any port works equally well; the app makes no network requests of its own.
